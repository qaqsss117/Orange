# 模块 06：UI、交互与资产

## 模块目标

使用共享 React UI 复刻原应用的主要视觉和流程，同时针对移动触控与桌面键鼠分别优化；任何源资产只有通过白名单审查后才能进入构建。

## UI-G0-001：设计 Token 与页面基线

**目标**：把参考截图/XML 转换成可复用设计系统。

**依赖**：`SEC-G0-001`。

**交付物**：颜色、字号、间距、圆角、阴影、状态色、响应式断点和截图基线。

**验收规则**：

1. token 不散落硬编码在页面；颜色、间距、字体和尺寸有命名变量。
2. 移动首页基线包含深灰背景、顶部入口、180dp 横幅、中央连接动画、状态、模式和节点入口。
3. 建立 360×800、412×915、平板、1366×768、1440×900 基线。
4. 桌面版使用侧栏/主工作区，不能把手机页面固定宽度简单居中放大。
5. 中文文案为 UTF-8 并通过词表校正，不复制原源码乱码。
6. light/dark、状态栏、安全区、窗口缩放和字体放大有静态示例。

**非目标**：不在此切片接真实 API。

**实现基线**：`src/designTokens.css` 统一定义颜色、字体、间距、圆角、阴影、状态、
触控尺寸、安全区、主题、字体缩放和减少动画 Token；`src/App.tsx` 仅使用审计后的
Orange 品牌图与 Lucide 通用图标，提供不接真实 API 的静态未配置状态。移动端保留
180px 订阅横幅、连接中心、状态、速率、模式/节点入口与底部导航；平板在 130% 字体下
保持全宽触控布局；1024px 起切换为侧栏和主工作区。五个固定视口同时覆盖亮/暗主题、
正常/放大字体与完整/减少动画，JPEG 基线进入资源清单并由
`scripts/security/check_ui_baseline.py` 校验尺寸、哈希、Token、断点、中文词表及无网络/
原生命令边界；证据见 `docs/evidence/UI-G0-001-design-baseline-2026-07-28.md`。当前缺少
Android/iOS/macOS 原生截图和正式设计审批，因此保持 `in_progress`。

## UI-G0-002：资产白名单与转换

**目标**：安全迁移可用视觉资产并记录许可证。

**依赖**：`SEC-G0-001`、`SEC-G0-004`。

**交付物**：`docs/asset-allowlist.yml`、处理脚本、目标资产目录、许可证记录。

**验收规则**：

1. 每项资产记录原路径、目标路径、SHA-256、用途、许可证、审查状态和审查人。
2. PNG/JPG/WebP 去除 EXIF；Lottie JSON 无外部 URL、脚本、隐藏二进制和未登记图片。
3. 普通工具图标优先 Lucide；VectorDrawable 只转换明确使用的旗帜/专有图形。
4. 第三方品牌 Banner 未获授权时不能进入 release 构建。
5. CI 拒绝未在 allowlist 的新图片、动画、字体和大资源。
6. 资产处理不读取原 APK/未知二进制，仅处理明确源文件。

**非目标**：不迁移原 geo 数据和核心资源。

## UI-P0-003：App Shell、认证与通用状态

**目标**：建立五平台导航、认证守卫和稳定通用交互。

**依赖**：`UI-G0-001`、`ARC-G0-002`、`API-P0-002`。

**交付物**：路由、启动/登录/注册、导航、Dialog、Toast、Loading、ErrorBoundary。

**验收规则**：

1. 未登录不能进入受保护页面；有效 token 恢复时不闪现错误账户内容。
2. Control Plane 启动、不可用、重试状态在认证页明确展示。
3. Android/iOS 返回手势、桌面浏览历史、Esc/关闭 Dialog 行为一致且不误退出 VPN。
4. 表单键盘导航、密码显示切换、提交 loading、字段/服务端错误完整。
5. 所有异步页面有 loading、empty、error、retry，不以空白屏代替。
6. ErrorBoundary 不显示 secret/内部 stack，提供安全重试或重启入口。

**非目标**：不实现社交账号登录。

## UI-P0-004：首页与连接主流程

**目标**：高保真呈现真实 VPN 状态和核心操作。

**依赖**：`UI-P0-003`、`VPN-P0-002`、`VPN-P0-004`。

**交付物**：首页、连接按钮/Lottie、状态、流量、模式、节点入口、Banner。

**验收规则**：

1. 连接按钮状态来自 Data Plane，不进行无法回滚的乐观伪状态。
2. 包含未配置、待授权、启动中、在线、停止中、失败、订阅过期状态。
3. 重复点击在启动/停止中被锁定；失败后可安全重试。
4. 上传/下载速度停止后归零，长单位和大数字不挤压布局。
5. Banner 失败使用本地白名单回退图，远程 host 未批准时不加载。
6. 五个基线尺寸截图通过；触控目标至少 44×44 CSS px，无重叠和文本截断。

**非目标**：首页不显示 bootstrap 节点详情。

## UI-P0-005：订阅、节点与配置页面

**目标**：完成订阅状态、节点选择、测速和基础配置管理界面。

**依赖**：`VPN-P0-003`、`VPN-P0-004`。

**交付物**：订阅卡片、selector 页面、测速、导入、更新、激活、删除确认。

**验收规则**：

1. 节点列表展示名称、状态、延迟和当前选择，选择后以 core 回读结果为准。
2. 测速可取消，timeout/unavailable 与真实延迟视觉区分。
3. 导入只通过用户主动文件选择或批准 URL，不请求照片库目录。
4. 删除激活配置前明确说明影响；删除失败不从 UI 假移除。
5. 更新和激活显示验证/预启动/切换阶段，失败保留旧配置。
6. 大列表滚动和筛选在目标低端设备/桌面下无明显卡顿。

**非目标**：不显示订阅 secret 或提供无警告导出。

## UI-P1-006：账户、商业与支持页面

**目标**：完成账户、套餐、订单、邀请和工单体验。

**依赖**：`API-P0-003`、`API-P1-004`、`API-P1-005`。

**交付物**：账户中心、套餐、订单、支付、邀请、工单和受控网页。

**验收规则**：

1. 账户用量、套餐、余额、版本和退出入口信息层级清晰。
2. 套餐周期/金额不截断，订单提交具备 loading 和重复提交保护。
3. 外部支付/客服打开前展示目标并通过 host 校验；取消后能返回原状态。
4. 工单内容安全渲染，不执行 HTML/JS，不提供图片附件入口。
5. 退出确认后先停止 Data Plane，再清理账户并进入可重新登录状态。
6. 桌面和移动布局分别通过截图与键盘/触控主流程。

**非目标**：不嵌入未经审核的远程全功能 WebView。

## UI-P1-007：响应式、可访问性与多语言

**目标**：保证五平台长期可用而非仅视觉接近。

**依赖**：所有 UI `P0`。

**交付物**：焦点规则、ARIA、字体缩放、键盘快捷操作、zh-CN 资源。

**验收规则**：

1. 所有交互可用键盘完成，焦点可见且 Dialog 有 focus trap/恢复。
2. 图标按钮有 accessible name/tooltip，状态不只用颜色表达。
3. 系统字体放大 1.3 倍无主操作遮挡；长邮箱/节点名有合理换行或截断提示。
4. 支持 prefers-reduced-motion，连接状态仍可无动画理解。
5. 屏幕阅读器能读出页面标题、连接状态、进度和错误。
6. zh-CN key 无缺失；未来语言缺失时回退明确，不显示 key 名。

**非目标**：P0 不承诺完整多语言翻译。

## UI-P2-008：Android TV 与大屏增强

**目标**：在明确纳入渠道后提供遥控器和电视布局。

**依赖**：`UI-P1-007`、`AND-P1-004`。

**交付物**：TV 导航、焦点图、Leanback manifest 决策、大屏截图。

**验收规则**：

1. 所有 P0 流程只用方向键/确认/返回可完成。
2. 焦点顺序稳定、可见，不进入不可退出区域。
3. 电视距离下字号和触控专用提示被替换。
4. 未完成 TV 验收时 release 不声明 Leanback 支持。

**非目标**：不在手机首发前阻塞主线，除非产品将 TV 定为首发渠道。
