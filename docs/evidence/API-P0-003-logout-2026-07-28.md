## Qualification Scope

This increment establishes a desktop-native logout transaction that stops and
verifies the Data Plane before deleting credentials or clearing account state.
It does not claim a production Data Plane adapter, product logout UI, mobile
business handler, real-backend E2E, or five-platform acceptance.

The WebView can request only the fixed `logout` command with schema version 1.
It cannot supply a URL, token, subscription credential, process path, file
path, shell command, or desired Data Plane state.

## Stop-Before-Secret Transaction

Login, registration, refresh, and logout share one native operation guard, so
no authentication mutation can overlap logout. `ManagedPlanes` performs the
authoritative Data Plane sequence while holding its coordinator lock:

1. refresh the adapter state;
2. stop the Data Plane;
3. refresh the adapter state again; and
4. require the final state to be `unconfigured`.

Only after that sequence succeeds does `BusinessApiService` delete the access,
refresh, and subscription credentials. The native session is changed to
`signed_out` and the public subscription cache is cleared only after all three
secret deletion attempts succeed.

A stop, read-back, lock, or protocol failure returns a stable native error
without touching credentials or cached identity. The secret backend attempts
all three deletions even when one fails. A partial deletion therefore retains
the native authenticated session and subscription cache so a second logout can
idempotently finish cleanup instead of reporting a false success.

## Desktop IPC And Permission Boundary

Rust, JSON Schema, and TypeScript define the same strict `LogoutRequest`: it
contains only `schemaVersion` and rejects unknown fields. The response reuses
the public `AuthSessionResponse`; frontend parsing rejects extra or secret
fields.

The `desktop-business` capability adds only `allow-logout` for the main window
on Linux, macOS, and Windows. Android and iOS do not register the handler. No
browser network, file, shell, browser-storage, logging, service, or platform
permission was added.
